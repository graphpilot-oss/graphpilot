# GraphPilot Token Savings Benchmark

Measures how many tokens a coding agent saves when it has GraphPilot tools
available vs falling back to raw file reads.

## Setup

```bash
cd benchmark
cp .env.example .env
# Edit .env — set ANTHROPIC_API_KEY

pnpm install
```

## Run (all steps)

```bash
pnpm all
```

This runs four steps in sequence:

| Step | Command         | What it does                                                                             |
| ---- | --------------- | ---------------------------------------------------------------------------------------- |
| 1    | `pnpm setup`    | Clone fastify v4.28.1, build GP locally, index the repo                                  |
| 2    | `pnpm generate` | Read fastify source → ask Claude to write 40 questions → compute GP ground-truth answers |
| 3    | `pnpm run`      | Run all 40 questions in **baseline** mode (file reads only) then **GP** mode             |
| 4    | `pnpm report`   | Generate `results/<timestamp>/report.md`                                                 |

## Run individual steps

```bash
pnpm setup      # only clone + index
pnpm generate   # only regenerate questions
pnpm run        # only run benchmark + report

# Partial runs
pnpm run -- --tasks=T01,T05,T10
pnpm run -- --mode=gp
```

## Output

```
results/
  2026-05-27T10-30-00/
    raw.json      ← full data (tokens, tool calls, answers, scores)
    report.md     ← human-readable markdown report
```

## What is measured

Each of 40 tasks runs in two modes against the **same fastify codebase**:

- **Baseline**: agent has `read_file` + `list_directory` only
- **GraphPilot**: agent additionally has `gp_recall`, `gp_callers`, `gp_callees`, `gp_impact`, `gp_stats`

Metrics captured per task:

| Metric         | Description                                        |
| -------------- | -------------------------------------------------- |
| `inputTokens`  | Tokens fed to the model (context + tool results)   |
| `outputTokens` | Tokens generated by the model                      |
| `totalTokens`  | Sum                                                |
| `filesRead`    | Number of `read_file` calls (baseline's main cost) |
| `toolCalls`    | All tool invocations                               |
| `correct`      | Whether answer contained ≥60% of expected keywords |
| `score`        | Keyword hit-rate (0.0–1.0)                         |
| `durationMs`   | Wall time                                          |
| `peakHeapMb`   | Heap delta during task                             |

## Task distribution (40 total)

| Type         | Count | Example question                                                |
| ------------ | ----- | --------------------------------------------------------------- |
| `navigation` | 10    | "Where is `buildErrorObject` defined?"                          |
| `callers`    | 10    | "What functions call `handleRequest`?"                          |
| `impact`     | 8     | "What breaks if I change `buildReply`?"                         |
| `trace`      | 7     | "Trace how a request flows from `fastify.route` to the handler" |
| `dependency` | 5     | "Does `reply.js` depend on `request.js`?"                       |

## Environment variables

| Variable            | Default             | Description                                 |
| ------------------- | ------------------- | ------------------------------------------- |
| `ANTHROPIC_API_KEY` | _required_          | Anthropic API key                           |
| `BENCHMARK_MODEL`   | `claude-sonnet-4-5` | Model for both modes                        |
| `FASTIFY_SHA`       | `v4.28.1`           | Git tag to clone                            |
| `MAX_TOOL_TURNS`    | `15`                | Max turns per task (prevents runaway reads) |
